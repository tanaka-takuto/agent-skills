# 仮定を検証する

案が成立するという主張を、確認できる証拠へ結びつける。

1. 案を支える事実、仮定、推定を分ける。誤っていた場合の影響、不確実さ、後から直す負担に基づき、結論を変える仮定を優先する。
2. 各仮定を、適用条件、予想される結果、反証となる結果で表す。合格条件と観察する証拠を確認前に定め、未知の数値や本人の許容値を捏造しない。
3. 判断に足りる最小の確認を選ぶ。既存資料、具体例の追跡、計算、実物の観察、小さな試作や実験を使い分け、追加確認の負担と判断への効果を考慮する。
4. 手段と権限があれば確認を実施し、条件、観察結果、根拠を残す。性能や実際の行動について、説明の整合や本人の賛同を実測の代わりにしない。実施できなければ検証計画として返す。
5. 期待を満たす例に加え、成立しない例、境界、失敗や変化のうち重要なものを調べる。結果が予想と違えば仮定か案を修正し、影響する結論を再評価する。
6. 主張ごとに、確認できた範囲、反証された内容、未検証、証拠の限界を示す。残る仮定には次の確認方法と、どの判断を保留または暫定にするかを結びつける。

「仮定・確認方法・得られた証拠・結論への影響」を簡潔に返す。計画と実施結果、条件付きの成立と一般的な保証を区別し、重要な仮定が残る案を検証済みと扱わない。
