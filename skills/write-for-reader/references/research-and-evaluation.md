# 調査根拠と評価

2026-11-20の読解・認知、技術説明・図表、既存の文章Skillの調査から、生成時の判断を抽出した。研究の結果と本Skillの設計判断は別であり、この手順全体の効果を研究が保証するものではない。

## 既存Skillとの境界

[yomiyasu v3.2.3](https://github.com/nanaism/yomiyasu/blob/v3.2.3/skills/yomiyasu/SKILL.md) と [natural-japanese](https://github.com/coji/natural-japanese/blob/main/skills/natural-japanese/SKILL.md) は、日本語の推敲、意味保持や構成の参考になる。[doc-coauthoring](https://github.com/anthropics/skills/blob/main/skills/doc-coauthoring/SKILL.md) には別コンテキストのAIを読者とする予備検査がある。main参照は調査時の状態で変わり得る。

本Skillは、読者の仕事から情報と表現を選ぶ工程を、説明・報告・手順に使える形でまとめた。既存Skillの本文を複製したり、同時適用を前提にしたりしない。日本語の局所的な修正だけなら既存Skillで足りる場合もあり、このSkillの新設自体を改善の証拠にしない。

## 効果を確かめる

「Skillなしで読者と目的を短く指定」「既存の推敲Skill」「本Skill」を、同じ素材・依頼・生成環境で比べる。全候補の比較が必要とは限らず、判断に足りる範囲を選ぶ。生成の比較には [evaluate-agent-skill](../../evaluate-agent-skill/SKILL.md) を必要に応じて使い、利用できなければ以下の観点で記録する。

| 成果           | 観測するもの                                                   |
| -------------- | -------------------------------------------------------------- |
| 読み始めやすさ | 初見で読むことを選ぶか、得られる答えと予想負担をどう捉えるか。 |
| 情報探索       | 必要な条件や例外を探す成功率、時間、見落とし。                 |
| 理解           | 要点や理由の言い換え、未掲載の具体例への適用とその根拠。       |
| 利用           | 正しい判断や操作、成功の確認、停止条件の理解。                 |
| 意味保持       | 必須情報の脱落、否定の逆転、断定の強化、数値の変化、追加事実。 |

想定読者の既有知識を分け、原案を読んだ学習効果が改稿の評価へ混ざらないよう、別の読者や同等の別素材を使う。好み、速さ、正答、確信を分け、必要な条件を失った稿を高い好感で救済しない。

AIによる点検は誤読候補を探す予備検査で、人間の読む意欲や理解を確かめた結果ではない。表示確認も理解の証拠とは別に残す。少数の例や文の長さ、禁則の件数だけで普遍的な改善を断言しない。

## 作成時の点検

2026-11-20に、条件ごとに別エージェントの新しい会話を使い、架空の7依頼をSkillなし／ありで各1回処理した。生成条件を伏せた別エージェントが事前基準と照合し、両条件の状況報告で「復旧期限は未定」を「復旧見込みは立っていない」へ広げる表現を指摘した。

不明・未定の対象と範囲を保つよう補強後、最終の本体と表現ガイドで7例を再生成し、未試験と性能不足を混同しない別の1例も点検した。重要な条件・形式の違反は認めなかったが、利用開始条件の反復は残った。比較の素材、事前基準、実際の出力、最終本体・表現ガイドのハッシュは [評価記録](evaluation-cases.json) に残す。再実行の解答者には依頼と素材だけを渡し、基準と過去の出力を混ぜない。

これは文章生成と意味保持の予備点検である。人間の理解、読む意欲、実ホストでの自動発動、図の描画は未検証。各条件内の複数例は同じ会話で処理し、独立した繰返しとは扱わない。最終稿と無Skillの同時再比較や既存推敲Skillとの比較も未実施であり、一般的な優位は主張しない。
