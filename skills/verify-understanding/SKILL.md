# 理解を照合する

同じ場面で同じ判断と期待結果を再現できるか確かめる。

1. 照合する内容と自分の解釈を短く示す。本人の発言にない補完は仮説として明示する。
2. 解釈の違いで結果が変わる具体例を選ぶ。典型例、似ているが対象外の例、境界例、失敗や例外のうち重要なものを使い、既に確認済みの例は繰り返さない。
3. 場面と、その解釈から予想される結果を示し、相手の期待との差を確かめる。必要なら先に相手の期待を聞く。一般的な賛同だけで、未提示の例まで一致したことにしない。
4. 見た目や体験は、参考例、避けたい例、比較で照合する。説明だけで判断できない場合は、実物や試作で確かめる事項として残す。
5. ずれがあれば、違う点が言葉の意味、適用条件、優先順位、期待結果のどれかを特定して修正する。例で確認した条件を超えて一般化しない。
6. 修正で影響する関連例を再確認する。回答から新しい意図や不足が見つかったら、それを照合結果と分けて返す。

確認できた解釈と具体例、修正点、まだ一致を確かめていない点を返す。認識の一致と、その要望で実際に目的を達成できることの検証を区別する。
