# 責務と境界を決める

誰が何を引き受け、何を約束して協働するかを明確にする。

1. 目的を達成する主要な流れ、扱う情報、守るべき条件、既存の制約を拾う。既存の境界がある場合は、その理由と変更可能な範囲を確認する。
2. 変わる理由、知識のまとまり、守るべき条件に基づき責務をまとめる。分割と統合の理由を示し、部品数や定型的な層の多さを良さと扱わない。
3. 各責務について、担当、所有する情報と判断、引き受けない仕事を定める。重複する判断、所有者のいない仕事、依存の循環を点検する。論理的な分割と物理的な分離を混同しない。
4. 境界を越える契約として、入力と出力、開始条件、結果の保証、失敗時の扱いを定める。必要なら順序、期限、重複、同時実行、変更時の互換性も明示する。
5. 代表的な場面を開始から終了までたどり、責務と契約だけで期待結果を説明できるか確かめる。失敗時と重要な変更時にも、判断の抜けや過度な調整が生じないか点検する。
6. 不整合があれば境界か契約を修正する。情報不足で決められない箇所は、必要な情報とその影響を残し、推測した境界を確定済みにしない。

責務と所有者、主要な依存と契約、流れで確認した結果を返す。表、構成図、状態や順序の図は判断の説明に必要なものだけ選び、変更をどこに閉じ込められるかを示す。
