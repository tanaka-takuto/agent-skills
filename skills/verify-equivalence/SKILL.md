# 同等性を確かめる

何が等しければ置き換えられるかを先に決め、差分を消すために比較基準を緩めない。

1. 基準と候補、対象範囲、守る契約、許可された差分、判定方法を特定する。基準の挙動は比較の証拠として扱い、基準と同じことだけで正しさを保証しない。
2. 入力、初期状態、権限、版、設定、時刻、外部応答と操作履歴を対応させる。同じ生データを使えない場合は意味を保つ対応を定義し、条件差と候補の差を混同しない。
3. 出力に加え、永続状態、権限、外部副作用、順序、失敗と回復を比べる。時刻や識別子の正規化、数値の許容差は契約上無関係と確認した範囲だけに適用し、順序や欠落を隠さない。
4. 通常、境界、例外、過去の不具合、低頻度の重要例、重複、競合を選ぶ。性能などの許容条件を結果を見る前に定め、母集団、選び方、未検証の範囲を残す。
5. 比較を許可された範囲で実施する。基準と候補の副作用を隔離し、比較だけのために実際の更新や送信を重複させない。実施できなければ検証手順として返し、結果を捏造しない。
6. 差分を回帰、許可された変更、条件差、比較方法の欠陥、未解決に分け、再現例と影響を残す。未解決や除外を一致に数えず、修正後は関連例と比較基準の妥当性を確かめる。

「比較条件・観測結果・差分と分類・判定の根拠・未検証範囲」を返す。同等性は検証した契約と条件に限定して述べ、少数の一致から全面的な互換性を断言しない。
