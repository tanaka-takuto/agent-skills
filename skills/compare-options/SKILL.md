# 選択肢を比較する

目的と制約の下で何を選び、何を引き受けるかを明確にする。

1. 今決めること、目的、動かせない制約、優先する価値を読み取る。既に選ばれた手段と、比較して決められる手段を区別する。
2. 結果や負担が実質的に異なる有力な案を作る。現状維持、小さな変更、追加しない案も適する場合は含める。弱い対抗案や同じ案の言い換えで候補数を増やさない。
3. 結論より先に、目的に基づく共通の評価基準を置く。導入だけでなく利用、維持、変更、撤退の負担も必要に応じて含める。推奨案が勝つように基準や前提を変えない。
4. 各案を同じ条件と粒度で評価し、事実、推定、未確認を区別する。必須条件を満たさない案を加点で救済しない。数値の根拠がなければ精密な点数や総合点を作らず、判断を分ける違いを示す。
5. 利点と引き換えの不利益、他の判断への影響、取り消しや切り替えの難しさを示す。重要な前提や優先順位が変わった場合に、どの案へ結論が変わるか確かめる。
6. 選択理由、受け入れる代償、確信の根拠、残る不確実性を伴う推奨を返す。判断を委任されていればその範囲で選び、AIの推奨と本人の合意を区別する。

重要な違いが読める短い比較と推奨を返す。追加の情報で選択が変わり得る場合は、その情報と確認方法を添える。どの条件でも最善の案があるとは扱わない。
