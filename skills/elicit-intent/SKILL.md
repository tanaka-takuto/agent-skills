# 意図を引き出す

相手が何を、なぜ求めているかを明確にする。

1. 会話と資料から既知の意図を拾い、本人の発言と自分の推測を区別する。答えが既にあることは聞き直さない。
2. 望む変化、避けたい結果、譲れない条件のうち、結論を変える不明点から聞く。抽象的な回答には、実際の出来事や一場面をたどって背景を確かめる。
3. 指定された手段が必須条件か、目的を満たす候補かを確かめる。好みや世界観も目的として扱い、効率や数値へ勝手に置き換えない。
4. まず中立的な開かれた質問で引き出す。言語化が難しい場合は複数の解釈や候補を示し、自由な修正、未定、委任も認める。推奨案への賛同から、元からその意図だったと推測しない。
5. 質問は前提が決まったものから、原則一度に一つに絞る。答えが相互に依存しない場合だけ少数をまとめる。
6. 目的と条件が衝突したら、どの場面で何を優先するかを聞く。AIが優先順位を確定しない。

得られた目的、望む結果、重要な条件と、まだ不明な意図を簡潔に返す。本人が確認した内容だけを確定として扱う。不明点が残る場合は、次に聞くこと、または質問以外で確かめることを示す。
