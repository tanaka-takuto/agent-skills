# Agent Skill の作成

1. 依頼から対象の作業、使う場面、想定環境、完了条件を特定する。既存の Skill とリポジトリの指示を確認し、重複を避ける。紛らわしい非対象の依頼があれば境界も決める。
2. 保存先の指定がなければ、このリポジトリの `.agents/skills/<name>/SKILL.md` に置く。`name` をディレクトリ名と一致させ、`description` に仕事と使用条件を簡潔に書く。
3. `SKILL.md` には結果を変える判断、手順、検証方法だけを書く。一般論や未確認の前提を増やさない。詳細資料は必要な場合だけ `references/` に、繰り返す決定的な処理は必要な場合だけ `scripts/` に置く。
4. [Agent Skills 仕様](https://agentskills.io/specification)に照らして frontmatter と参照先を検証する。実際に使う依頼と、使うべきでない近い依頼で発動条件を確認し、未検証の点を報告する。

常時適用する規則や機械的な強制には、それぞれリポジトリ指示やフックが適する場合がある。依頼された Skill の目的を保ちつつ、該当する場合は理由を伝える。
