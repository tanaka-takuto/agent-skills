# Agent Skill のレビュー

1. 対象の `SKILL.md`、必要な付属ファイル、元の依頼を読む。想定する利用環境が不明なら、その前提を明示する。
2. [Agent Skills 仕様](https://agentskills.io/specification)への適合、参照先と依存関係を確認する。対象ホスト固有の項目はその仕様で確認し、仕様違反と推奨事項を分ける。
3. `description` が適切な依頼で発動するか、手順が目的と完了条件を満たすかを確認する。冗長な一般論、重複、古くなりやすい情報、不要な制約を指摘する。スクリプトと権限の危険も確認する。
4. 可能なら使うべき依頼と使うべきでない依頼で動作を試す。未実施の検証は未検証と記す。
5. 問題を重要度順に、ファイル位置・影響・具体的な修正案とともに報告する。問題がなければその旨を述べる。修正は依頼された場合に行う。
